# Experiment reports

Substantive studies live in `YYYY-MM-DD--short-name/`. Before running, state the
question, inputs/splits, experimental unit, metrics, comparisons, seeds, and
time/memory/disk bounds. Log exact commands, commit/dirty state, package versions,
hardware and input hashes. Keep raw data/checkpoints in ignored `local_data/`.

Report methods/reproduction, observed results (including failures), interpretation
and untested claims separately. Small smoke tests do not measure generalization.
Keep aggregate machine-readable results and runnable analysis. Completed reports
are historical records: add follow-up reports for corrections, not silent edits.
